STATISTIK RISIKO
Fitur Scanning

Sistem WebSec Checker melakukan analisis keamanan website melalui beberapa fitur utama yang saling terintegrasi. Setiap fitur dirancang untuk mengidentifikasi potensi risiko berdasarkan data aktual dari target.

OSINT & Network
Mengambil informasi IP, WHOIS, dan subdomain untuk melihat attack surface.
SSL/TLS Analysis
Memeriksa sertifikat SSL, masa berlaku, dan protokol keamanan.
Security Headers
Mengecek header seperti X-Frame-Options, CSP, X-Content-Type-Options, Strict-Transport-Security, Referrer-Policy, Permissions-Policy.
Port Scanning
Mendeteksi port terbuka dan layanan yang berjalan pada server.
Directory Scan
Mencari file sensitif seperti .env, .git, backup, dan config.
Data Detection
Mendeteksi API key, password, secret, dan private key.
Dynamic OWASP Mapping
Mengklasifikasikan temuan ke OWASP Top 10:2025 berdasarkan evidence hasil scan.
CVSS v3.1 Scoring
Menghitung tingkat risiko secara dinamis berdasarkan hasil scan.
Deteksi Tidak Valid
Menggunakan baseline 404, soft 404, SPA detection, dan validasi content-type.
